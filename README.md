# נר נשמה - יומן ימי פטירה (יארצייט) משפחתי עם סנכרון ליומן גוגל

מערכת אינטרנטית לניהול ימי פטירה של אבות המשפחה לפי לוח השנה העברי, חלוקה לענפי משפחה וסנכרון חי ליומן גוגל (Google Calendar) באמצעות פיד WebCal/iCal דינמי.

---

## תכונות מרכזיות במערכת

1. **חישוב הלכתי מדויק של יום השנה:**
   * מבוסס על מנוע לוח השנה העברי המוביל `@hebcal/core`.
   * **התחשבות בשקיעת החמה / צאת הכוכבים:** סימון האם הפטירה הייתה לאחר השקיעה מעביר את יום הפטירה העברי אוטומטית ליום הבא.
   * **שנים מעוברות:** טיפול חכם בחודש אדר (אדר א׳ / אדר ב׳) לפי מנהג הפוסקים.
   * חישוב אוטומטי של תאריכי יום השנה הלועזיים לכל שנה קדימה.

2. **הצגת תאריכים לפי האפיון:**
   * **התאריך העברי הוא המרכזי והמוביל**, והתאריך הלועזי של יום הפטירה המקורי מופיע בסוגריים בלבד:
     > **דוגמה:** י״ז באדר תשמ״ב (12/03/1982)

3. **שם משפחה ייעודי:**
   * שדה שם משפחה נפרד ומודגש, המשמש לזיהוי ולמניעת כפילויות.

4. **מנגנון מניעת כפילויות והתראות אי-התאמה:**
   * אם מוזן נפטר עם שם זהה שכבר קיים במערכת אך עם תאריך שונה, המערכת מקפיצה חלון אזהרה:
     > *"שים לב: קיים כבר נפטר בשם X עם תאריך שונה. האם מדובר באותו אדם עם תיקון תאריך, או בנפטר נוסף בעל שם זהה?"*

5. **פרויקטי יומן עצמאיים ומבודדים (Multi-Tenant):**
   * יצירת יומנים משפחתיים נפרדים ללא שום ערבוב מידע.
   * המשתמש הראשון שפותח פרויקט יומן הופך אוטומטית ל**מנהל היומן** (Admin).

6. **סנכרון ליומן גוגל לפי ענפי משפחה (Dynamic WebCal):**
   * כל בן משפחה בוחר אילו ענפים לסנכרן (למשל: "צד אבא בלבד").
   * המערכת מייצרת קישור `webcal://` אישי.
   * ביומן גוגל מוצגים רק הנפטרים מהענפים שנבחרו, והאירועים מתעדכנים בכל שנה אוטומטית!

## התקנה והרצה מקומית

```bash
# התקנת תלויות
npm install

# הרצת שרת פיתוח
npm run dev
```

פתח את הדפדפן בכתובת: `http://localhost:3000`

## פריסה בחינם (Free Deployment)

### א. פריסה ב-Vercel (חינם לחלוטין)
1. דחוף את הפרויקט ל-GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Yahrzeit calendar system"
   gh repo create anniversary-calendar --public --source=. --push
   ```
2. היכנס ל-[Vercel.com](https://vercel.com) (באמצעות חשבון GitHub).
3. לחץ על **"Add New Project"**, בחר את המאגר `anniversary-calendar` ולחץ **"Deploy"**.
4. תוך פחות מדקה האפליקציה תהיה באוויר עם כתובת אינטרנט ציבורית ותעודת SSL!

### ב. חיבור מסד נתונים Supabase (אופציונלי)
המערכת מגיעה מוכנה לעבודה מקומית ומכילה קובץ סכמה עבור Supabase:
* קובץ ה-SQL נמצא ב-`supabase/schema.sql`.
* העתק והרץ את תוכנו ב-SQL Editor של פרויקט ה-Supabase שלך.
